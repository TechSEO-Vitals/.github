# TechSEO Vitals

**Enterprise Technical SEO Consultant.**

I help large sites stop leaking traffic and revenue to technical issues nobody's looking at. A migration that quietly drags rankings down for months. Indexing problems that hide in the long tail. An AI crawler that can't read half the content. I find those leaks, rank them by what they actually cost, and hand over a plan your team can ship.

I spent more than ten years shipping production code before going deep on technical SEO. So what I hand back isn't a 200-page audit nobody reads — it's concrete tickets a dev team can pick up on Monday morning.
